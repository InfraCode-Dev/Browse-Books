# Browse Books

A static, self-contained gallery of a library starting from the **Audible Library Extractor (ALE)** browser extension (gallery format v0.2.12).

It's plain HTML/CSS/JS with no build step or server required — open `index.html`
in a browser, or serve the folder over any static host (it ships a `.nojekyll`
file for GitHub Pages). All library data lives in `data/`; the UI bundle lives in
`assets/`.

## Built with

This gallery and its export format come from the Audible Library Extractor project:

- Source: https://github.com/joonaspaakko/audible-library-extractor
- Documentation: https://joonaspaakko.gitbook.io/audible-library-extractor/
- Chrome extension: https://chromewebstore.google.com/detail/audible-library-extractor/deifcolkciolkllaikijldnjeloeaall
